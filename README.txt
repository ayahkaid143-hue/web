موقع آية قايد الحيلة — Aya Qaed Al-Hilah

طريقة المعاينة:
1) فكّي ضغط الملف.
2) افتحي مجلد aya_portfolio.
3) افتحي index.html في المتصفح.

طريقة الرفع على GitHub Pages:
1) أنشئي مستودعاً جديداً (Repository) في GitHub.
2) ارفعي جميع محتويات هذا المجلد، مع مجلد assets كما هو.
3) من Settings ثم Pages اختاري Deploy from a branch.
4) اختاري main ثم /root واضغطي Save.
5) انتظري حتى يظهر رابط الموقع.

الملفات:
- index.html : بنية الموقع ومحتواه.
- style.css : التصميم والألوان والتجاوب مع الجوال.
- script.js : القائمة المتنقلة ومؤشر التقدم والتنقل.
- assets/aya-cartoon.png : الرسم الكرتوني المستخدم في الموقع.

ملاحظات التخصيص:
- زر البريد يفتح رسالة بريد جديدة دون عنوان محدد؛ أضيفي بريدك لاحقاً عند الرغبة.
- بطاقات الأعمال الحالية تعرض مجالات اهتمام وتعلم، وليست ادعاءً بإنجاز مشاريع فعلية.
- يمكن استبدال الرسم داخل assets مع الاحتفاظ بالاسم aya-cartoon.png.
